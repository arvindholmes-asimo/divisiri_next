# Product claim review (internal)

Copied from the design mockup's review notes. These are not legal approval.
A product stays a draft, hidden in production, until its claims, label and price are approved.

| Product | Review note |
|---|---|
| Bonfortis-K2 | 'Helps prevent osteoporosis' is a disease-risk claim: reword to 'supports bone density and calcium absorption' unless approved under FSSAI Schedule. |
| CharcoalPro | 'Clinically Proven' needs a study dossier on file; otherwise use 'Science-backed ingredients'. |
| CordyVital | Do not use the label-spec line on chemo/radiation tolerance on public pages; keep it for the HCP portal only. |
| DailyVit | Low risk. Keep RDA percentages exactly as on label. |
| GreenGood | 'Improves oxygen saturation' and 'haemoglobin' claims need substantiation; soften to 'supports healthy blood and vitality'. |
| Healogen | Medical-nutrition product: sell with 'use under medical supervision' and route via HCP / hospital channel first. |
| HerbaGut | IBS / GERD are disease terms: use 'supports digestive comfort' on consumer pages; disease wording only in HCP material. |
| Herbosome | Analgesic, antipyretic, ulcer and IBD claims are drug-like: high risk for an FSSAI product. Reword for the web. |
| MenMaxx | HIGH RISK: sexual-function claims and Sarpagandha (yohimbine) content. Needs regulatory sign-off; Google/Meta ads will restrict. |
| MomVit | Use 'formulated to the UNIMMAP composition recommended by WHO/UNICEF'; avoid 'UNICEF & WHO approved product'. 'Prevents anemia' needs rewording. |
| OmegaSea | Low-medium risk. Keep 'supports' wording. |
| Optimeal Max | FSMP: label and pages must state 'Recommended to be used under medical advice only'. |
| Optimeal Pro | Medical nutrition: HCP-first. 'Prevents sarcopenia in oncology patients' only in HCP material. |
| Orthoflex Pro | 'Improves stem cell production' is an unproven structure claim: needs evidence or softer wording ('nutrients studied for cellular health'). |
| Power Fresh+ | Contains caffeine: add 'Not recommended for children, pregnant or lactating women' warning. |
| Primmune Pro | 'Protection against seasonal flu' is a disease-prevention claim: reword to 'supports natural immune defences'. Pack count: label spec says 60, mock-up says 30. Confirm. |
| SAD-Nil | 'Depression' is a disease term: remove from consumer pages. |
| SHREDD-360 | '100% natural, no side effects' and 'fat burner' attract ad-policy flags; use 'supports metabolism'. |
| SLEEP Support | Label spec says '1 Sachet'; product is capsules. Fix serving text. |
| STRESS-Nil | Spec mentions a sachet variant ('StressNil Sprinkles'); confirm the capsule is the launch format. |
| VitaDK7 | Label spec flags 'sold under prescription only'. Confirm whether this is OTC before listing on e-commerce. |
